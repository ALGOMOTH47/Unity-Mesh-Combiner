# Unity-Mesh-Combiner
This is a mesh combiner for the unity game engine.


This allows you to convert multible meshs into one draw call for the GPU.

This Package Includes:  

MeshCombiner Script
AllowCombine Script

Useage:

Setup:
1. Crete a Empty Game Object And add the MeshCombiner Script on the gameobject
2. Click on the three Dots on the Right Courner of the script window
3. click on Setup
4. Go to the gameobject that you want to combine (the gameobject must have a mesh filter and Mesh renderer on it to function) and click allow on the AllowCombine Script.
   
Combing:
   
1. Go Back to the gameobject with MeshCombiner on it.
2. Click on the three Dots on the Right Courner of the script window
3. Click On Combine


Saving Meshs:
1. Click on the three Dots on the Right Courner of the script window
2. Click Save
3. Pick The Foldor To Save The Mesh to and Chose a name for the file
4. Click Save
5. And Your Done.

You can also apply combine the mesh on start although this does not apply colliders.
